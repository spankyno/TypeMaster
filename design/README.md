# Fuentes de los recursos gráficos

- `og-image.html` → imagen Open Graph / Twitter (1200×630). Capturar a 1200×630 → `public/og-image.png`.
- `icon.svg` → favicon (`public/favicon.svg`) y variante «any» de los iconos del manifest.
- `icon-maskable.svg` → iconos *maskable* (192/512) y `apple-touch-icon` (180×180); el símbolo ocupa la zona segura.

No forman parte del build de la aplicación.
